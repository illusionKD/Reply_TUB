# Mob Programming Guide

Each team works together on one shared screen or laptop.

## Roles

- **Driver:** Operates the laptop and Kiro.
- **Navigator:** Guides the implementation and reviews decisions.
- **Product thinker:** Checks the business requirements and user experience.
- **Tester:** Tests the application and identifies failures.
- **Timekeeper/observer:** Tracks time and blockers.

## Working rules

1. Discuss the next step before implementing it.
2. The driver does not make decisions alone.
3. Review Kiro-generated code before accepting it.
4. Rotate the driver every 10–15 minutes.
5. Test frequently.
6. Prioritize the minimum viable product.
7. Ask the facilitator for help when blocked for too long.
