# Definition of Done

A team can demonstrate the following:

- [ ] The application is deployed to AWS (API Gateway + Lambda) and reachable via a live endpoint — not running only on localhost.
- [ ] A user can enter a customer ticket.
- [ ] A user can select or enter a category.
- [ ] The application invokes Amazon Bedrock.
- [ ] A response draft is displayed.
- [ ] The human-review warning is visible.
- [ ] Empty input is handled.
- [ ] At least one missing-information ticket is tested.
- [ ] At least one difficult customer ticket is tested.
- [ ] The team can explain one important design decision.

## Stretch goals

Only attempt these after the MVP works:

- Automatic ticket classification.
- Editable response drafts.
- Regenerate response.
- Tone selection.
- Escalation recommendation.
- Missing-information detection.
- Response quality checklist.
- Comparison of two prompts.
