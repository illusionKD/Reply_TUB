# Initial Kiro Prompt

Copy this prompt into Kiro after reading the repository documentation.

```text
You are helping us build an AI-powered customer support ticket assistant for Musterhandel Retail GmbH.

First, read all files in the docs folder, especially:
- business-context.md
- ai-behavior-guidelines.md
- functional-requirements.md
- architecture.md
- definition-of-done.md

Then:
1. Inspect the existing repository.
2. Summarize the business problem.
3. Summarize the minimum functional requirements.
4. Identify assumptions and missing information.
5. Propose a simple architecture.
6. Create an implementation plan in small, testable steps.
7. Do not implement the entire application in one step.

Prioritize a working minimum viable product.
Do not add stretch goals until the minimum requirements work.
Review generated code for security, input validation, error handling, and maintainability.
```
